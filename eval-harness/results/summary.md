## 6. Caveats

- n = 26. A perfect catch of 6/6 release-blocking answers supports a catch rate of only about 61% or more (95% lower bound).
- The rubric, rules and reference labels were written after reading the sample. The judge prompt is generic and was frozen before any judge output was seen.
- The judge and the replay check answers against the full guide; a production guardrail would see only retrieved chunks, so these results are optimistic.
- Retrieved contexts are not logged, so retrieval failures cannot be separated from generation failures.
- Tier-1 uses TF-IDF (lexical); DoorDash used a semantic similarity check.
- The reference-label draft and the judge are the same model family; the judge ran in an isolated process without access to the labels. Human sign-off: 26/26 labels.
- Mean judge cost per call is lower on repeat runs because the system prompt and guide are prompt-cached.
